# Wallpaperi 设计

用户已确认 macOS 原生方案。最低系统 macOS 13，SwiftUI + AppKit，无第三方依赖。

五个 Tab：当前壁纸、壁纸筛选、显示与轮换、下载与存储、通用设置。菜单栏提供立即更换、暂停和打开窗口。窗口关闭后应用继续运行，退出应用才停止轮换。

Wallhaven API v1 搜索使用 q、categories、purity、atleast 和 sorting=random。NSFW 默认关闭，启用必须提供 API Key，Sketchy 单独开关。Key 通过官方支持的 X-API-Key 请求头发送，存储在钥匙串，不进入 URL、配置、历史或日志。所有下载检查来源域名、图片类型及实际尺寸。

读取每块显示器当前模式的像素分辨率；根据最小宽高检索，在客户端按宽高比筛选，容许 6% 比例差并使用居中填充。不放大低分辨率图片；找不到匹配结果时保留原壁纸。支持主屏或所有显示器逐个更换，多屏部分成功时明确反馈。

自动轮换默认关闭，默认间隔 60 分钟，可选 5 分钟至 24 小时。睡眠唤醒后最多补一次，不累积任务。串行请求，避免重叠，429 等待后续轮换。保存设置、关闭自动轮换或显示器变化时取消正在进行的任务。

用户可选下载目录，默认 ~/Pictures/Wallpaperi，原子保存、保留历史；不自动删除文件。通知默认关闭，打开时申请系统权限。SMAppService 实现登录启动。普通配置为 Application Support 中 JSON，历史存储本地绝对路径。

测试核心过滤、请求编码、状态码、重复过滤和真实结构解码；编译整个应用并打包 .app。没有用户 API Key 时不宣称完成认证接口联调；当前机器桌面实际改变仅作为用户点击更换后的效果。
